# Pool Pulse

Proactive pool water chemistry care, smart prescription dosing, weather buffer advisor, and chemical inventory tracker built with Kotlin & Jetpack Compose.

## Features
- **Pulse Dash**: Water balance overview, tomorrow's maintenance outlook, and live 3-day Open-Meteo weather forecast with proactive +1.5 ppm Free Chlorine weather buffers.
- **Water Vitals & CSI**: Interactive inputs, customizable ideal ranges & targets, and automatic Calcite Saturation Index (CSI) calculation.
- **Smart Prescription**: Volume-scaled dosing recommendations with estimated cost and one-tap inventory deduction.
- **Pool Doc**: Live vitals-aware troubleshooting for cloudy water, algae, foam, and eye irritation.
- **Reminders, Chem Locker & Cost Log**: Custom maintenance reminders, brand/UPC lookup for chemical restocking, and full dose & receipt history.
